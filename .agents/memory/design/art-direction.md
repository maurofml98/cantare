# Cantare · O Instrumento

## Filosofia
Cantare NÃO é dashboard, landing page ou site. Cantare é um **instrumento profissional**.
Referências: Apple Logic Pro, Ableton Live, DaVinci Resolve, Arc Browser, Apple Music, Porsche Digital Cockpit, Bang & Olufsen, Teenage Engineering.
Sensações: precisão, silêncio, confiança, luxo, respiração.

## Regras absolutas
- **Sem texto emocional decorativo.** Cortar "Boa noite", "O teatro está aberto", "A cortina", "Descubra sua tessitura". Cada palavra precisa existir por um motivo funcional.
- **Reconhecimento visual > leitura.** Mais imagens, ícones, estados, componentes. Menos parágrafos.
- **Hierarquia instantânea:** onde continuar, quantos exercícios faltam, qual projeto ativo, próximo passo, quanto falta.
- **Cards têm identidade própria** por mundo:
  - Treino → ondas sonoras + progresso circular
  - Saúde Vocal → anatomia dourada em lineart
  - Repertório → vinil + agulha
  - Palco → cortinas + iluminação teatral
- **Materialidade física obrigatória:** vidro, metal, latão, veludo, madeira, luz, reflexo, profundidade. Nunca flat, nunca neon, nunca glassmorphism óbvio.

## Paleta (imutável)
- Fundo `#07080A` · Card `#0D0D0F` · Ouro `#B8955A` · Marfim `#E8E4DC`
- Tipografia: Cormorant Garamond (números/display, 300) + DM Sans (labels/UI, 300-400). Numerais romanos como marcadores.

## Animações — microinterações discretas
- **Hover cards:** não escalam. RESPIRAM. Borda dourada suave, profundidade aumenta, iluminação sobe.
- **Clique:** escala 0.985-0.99 imediato, shadow muda, depois navega. Nunca atrasado.
- **Portal (troca de mundos, ~700ms):** feedback imediato → escurecimento localizado → mundo some → novo emerge → luz muda → cascata de conteúdo.
- **Entrada da tela em cascata:** background → sidebar → hero → cards → painel direito → listas. Delays pequenos.
- **Cards entrando:** deslocamento 6-12px + fade + blur mínimo. Nunca bounce.
- **Botões:** hover com borda dourada + reflexo. Pressed escurece → retorna → executa.
- **Gráficos:** linhas desenhadas (não instantâneas).
- **Ondas sonoras:** respiram, amplitude varia.
- **Vinis:** rotação lenta quase imperceptível. Hover move agulha alguns graus.
- **Anatomia:** energia sutil passando pelas linhas.
- **Partículas:** existem mas quase invisíveis, só perto de luzes.

## Responsividade
Desktop ≠ mobile reduzido. Mobile é outro produto com o mesmo DNA — outra composição, hierarquia de toque.

## Missão
Quando o cantor abre o Cantare, sente que está usando o melhor aplicativo de canto do mundo. Se dúvida entre "mais bonito" e "mais fácil de usar", vence usabilidade — sem abrir mão da elegância.

## Proibido (do briefing antigo)
Não escrever pull-quotes editoriais, saudações longas, marginália, ou frases contemplativas ocupando espaço útil. Cortar texto emocional. Cortar "sua voz, seu palco" fora do logotipo.

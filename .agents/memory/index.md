# Project Memory · Cantare

## Core
Cantare É um **instrumento profissional** (Logic Pro, Ableton, Arc, B&O). NÃO é dashboard, landing ou site editorial.
Paleta imutável: fundo #07080A, card #0D0D0F, ouro #B8955A, marfim #E8E4DC. Nunca roxo/neon/glow.
Tipografia: Cormorant Garamond (300) + DM Sans (300-400). Numerais romanos I-V como marcadores.
Sem texto emocional decorativo. Reconhecimento visual > leitura. Cada card tem identidade própria (ondas/anatomia/vinil/cortinas).
Materialidade física: vidro, latão, veludo, luz. Hover respira (não escala). Clique escala 0.985. Portal ~700ms.
Lovable Cloud DESATIVADO — não implementar features com backend/auth/DB até user habilitar.
